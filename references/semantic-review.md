# 语义复核

## 高风险语言

逐条检查包含以下含义的源译对：

- 否定：`not`、`no`、`without`、`neither`、`nor`；
- 不确定性：`may`、`might`、`could`、`suggest`、`appear`、`likely`；
- 关联：`associate`、`correlate`、`predict`、`relate`；
- 因果：`cause`、`lead to`、`result in`、`effect`；
- 比较级和最高级；
- 人群、样本和情境限制；
- 研究设计与时间边界；
- 局限和未来研究。

源语言不是英语时，使用目标学科中等价的高风险词清单，不得只扫描上述英文词。

## 证据强度

- 相关不是因果；
- 预测不是机制；
- 横断面证据不能确立方向；
- 开放试验不是随机对照试验；
- 参与者引语不是总体估计；
- 自传式设计案例不能外推为普遍有效；
- 设计启示不是已经验证的产品效果。

这些是复核者判断证据边界时使用的准则，不是可以自动补进作者正文的句子。
译文只能保留源文已经表达的限制。若源文没有写“不能外推到产品”“不能证明
因果”“不是直接检验的机制”或“本毕设方案尚未有效”，不得为了显得严谨而
自行加入。项目适用性、产品启示和审查意见应进入独立证据笔记，与译文数据
和候选 PDF 正文分开。

校验器会检查高频审查表达：译文出现“本项目/本毕设”、外推限制、不能证明
因果或产品效果、不是直接检验的机制等表述时，对应源文单元必须含有相应的
原始依据。没有依据就阻断 translated 阶段。

## 数字核对

保留：

- 样本量和分组人数；
- 百分比及分母；
- 均值、标准差和置信区间；
- 系数、p 值和效应量；
- 图表编号；
- 题项编号和计分方向；
- 作者年份引文和数字引文。

## 复核深度

翻译 Agent 先修复自动报告中的明确问题。用户开启审校模式时，独立检查者重新检查：

- 摘要；
- 方法和样本；
- 结果；
- 局限；
- 结论；
- 所有高风险语言；
- 复杂表格、量表和图。

普通正文也不得因为页面看起来简单而跳过。否定、不确定性、证据强度、
数字、时间点、样本、统计符号、跨栏跨页续句、摘要、结果、局限和结论均须
完整复核。发现一个系统性错误，扩大到相邻章节、同页面类型或全文同类表达。

## 高风险单元标记

翻译数据中至少使用以下稳定标记：

- `semantic-boundary`：否定、不确定性、相关/预测/因果边界与作者推测；
- `semantic-high-risk`：结论、局限或可能改变论证方向的关键句；
- `statistics-or-sample`：样本、统计量、显著性、效应量与研究设计；
- `instrument-item-or-scoring`：量表、问卷、测验或其他测量工具的题项、
  选项方向、分量表归属与反向计分。

标题、正文与测量工具中的这些单元必须逐单元出现在候选 PDF 文本层。历史
作业中以具体工具名开头、但以 `-item-or-scoring` 结尾的标记继续按同等风险
处理。表格文本抽取可能改变列顺序，表格统计仍需依靠数值核对和结构清单；
审校模式再由独立检查确认。不得依靠整篇 85% 覆盖率放过局部静默改写；
若排版器必须改写字面形式，应先同步更新译文数据并重新注册候选。

## 记录格式

每个问题记录原文位置、候选译文、问题类型、修复结果和残余不确定性。不能只写“已检查”。
