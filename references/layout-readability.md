# 版式与可读性

## 优先级

1. 语义正确；
2. 目标语言阅读舒适；
3. 图、表、注释和参考文献完整；
4. 页序与结构对应；
5. 视觉细节相似。

不得为了保留英文碎文本框牺牲前三项。

## 字体与行距

具体数值从 `job.json` 的质量配置读取。简体中文默认值见质量合同。

- 正文、图注、脚注、版权行和参考文献必须按层级区分；
- 较小层级仍要可读，并在 `layout_overrides.json` 中标记非正文区域；
- 目标语言缺字时更换字体或嵌入回退字体，不使用不可检索的轮廓字替代；
- 字体回退不得造成同一段落视觉跳变。

## 页面空间

功能性留白服务章节层级、图表或视觉呼吸；机械留白来自碎文本框替换。

当正文低于目标字号或行距、同页同栏仍有大片空白时，依次：

1. 延长合法文本区域；
2. 按自然段落重新流排；
3. 增加行距；
4. 恢复正文目标字号；
5. 重平衡栏目；
6. 调整图片环绕但不裁图；
7. 写入页面级 override。

不接受“上半页拥挤、下半页空着”的候选。

普通正文采用文档级字号计算，不逐页缩放：

- 先用全部普通正文页的译文、批准版心、目标行距和自然段距试排；
- 以最密页仍能完整容纳为约束，选择全篇可使用的最大正文字号；
- 选定后冻结全篇普通正文的字号和行距，一级标题、二级标题、注释与页眉
  按该正文基准的稳定比例派生；
- 个别密页只能在批准的正常版心范围内扩大文本区域或减少非必要段距，
  不能单独缩小正文；
- 个别短页不能把正文机械切成句组，再用超大 `spaceAfter` 追赶原文高度。
  自然短页允许保留合理留白。

### 自适应字号算法

“根据字数计算”不能简化为 `字号 = 页面面积 / 字数`。中文、英文、数字、
公式、标点和标题的实际宽度不同，最终决定必须来自真实字体的换行测量。

标准算法：

1. 对每个普通正文页记录实际译文非空白字符数、自然段数、一级/二级标题数、
   注释数、批准版心宽度和可用高度；
2. 从 `job.json.quality.typography_search` 读取字号、行距、段距和标题比例的
   搜索范围，论文专属生成器不得另藏一套常量；
3. 先按“译文字数 / 可用面积”估计页面密度，用于优先试排可能最密的页面；
4. 对每组候选字号和行距，使用最终交付字体、真实段落样式和批准版心逐页
   换行，测量实际内容高度；
5. 出现溢出、单字孤行、超出最密页舒适填充率或非法版心时，拒绝该候选；
6. 项目默认优先保持舒适行距，再选择该行距下可用的最大统一正文字号；
7. 正文确定后，以全篇标题集合为样本，在配置比例范围内选择统一的一级、
   二级标题字号；不得因某一页短或密而单独改变标题或正文字号；
8. 参考文献、表格、图注、脚注和量表属于独立文字角色，可分别计算统一层级，
   不能简单由正文乘一个固定比例；
9. 把每页画像、所有入选页的实测填充率、最密页、失败候选样本和是否命中
   搜索边界写入 `generator-layout-log.json`，供人工复核。

若入选字号恰好等于搜索上界，不能直接宣称“最优”；必须扩大试排范围，或
用有依据的舒适填充率、源文层级和人工样张说明为何停止。

横向版心不能被当作压缩纵向内容的旋钮。普通正文默认保持原文的正文宽度、
栏数和左右页边距关系，不得为了减少底部留白，把原本接近通栏的正文收成
居中的窄长栏，制造左右大片无意义空白和高频断行。

- 先保持源文正文宽度，再调整自然段流、字号、行距和段距；
- 源文单栏默认继续使用接近源文的单栏宽度，源文双栏默认保持双栏关系；
- 标题页、表格、图形、量表和明确批准的新版式可单独处理，但不能把特殊页
  的窄栏规则扩散到普通正文页；
- 只有任务明确批准横向新版式时，才能在页面 override 中设置
  `horizontal_width_change_justified: true` 并写明具体理由。

当单栏或半栏底部可用空白达到约 25% 时，即使字号刚过硬下限，也必须重新判断是否还能改善阅读：

- 普通正文优先恢复优选字号与 1.50–1.60 行距；
- 量表、清单、评分键和表单优先增大题项行距、行组间距、段间距或字号；
- 短页可以保留功能性留白，但必须在 `layout_overrides.json` 的页面 override 中设置 `sparse_layout_justified: true` 并写明原因；单页用 `page`，同一理由覆盖多页时可用 `pages` 数组；
- “页数要与原文一致”本身不是让文字挤在上半页的充分理由。

`body_font_target_pt` 与 `leading_target` 是默认目标区间，不是禁止继续放大的上限。若译文同一栏的底部空白比原文多出 25 个百分点以上，必须结合顶部留白和内容分布复核：只有“顶部紧贴、底部空旷”的明显失衡才直接阻断；上下相对平衡、字号行距达标且横向版心正常的天然短页进入人工复核，不得为了通过单一底部指标而机械下移整页、极端拉大段距或收窄栏宽。最后一页、固定表单或天然短页也必须先完成可读性优化，再说明剩余留白。

## 断行

### 中文

- 按段落或语义区域流排；
- 禁止长标题或正文续行只剩一个汉字；正常的单字章节编号只有在具有明确
  层级和充分前后间距时才可保留；
- 避免闭合标点出现在行首、开放标点停在行末；
- ReportLab 路线使用 `scripts/cjk_markup.py` 的短 `<nobr>` 组和 CJK 分行补丁
  实现标点禁则；不得插入 U+2060、零宽字符或其他会污染 PDF 文本层的
  不可见连接符；
- 标题尽量与后续正文同页；
- 不拼接左右栏，也不把续句拆离原段。

### 日文与韩文

- 使用目标语言断行规则和字体回退；
- 保留必要的禁则处理；
- 不照搬中文标点与字间距假设。

### 拉丁字母语言

- 开启词级换行和合适的连字符策略；
- 不把原文语言的词长假设直接套到目标语言；
- 引文、公式、URL 和代码不得被错误断开。

## 图与表

- 保留图片比例、清晰度和对应图注；
- 只有承担论文信息的图内标签才使用覆盖或重建完成本地化；
- 照片、装饰图、正式标志和不依赖内部文字理解的截图保持原图，不叠加译文；
- 表格列关系含糊时重建表格；
- 禁止用白块遮住溢出内容；
- 不得把图表压缩到无法阅读，只为维持原页。

## 溢出处理

依次使用现有空白、扩大合法区域、重平衡栏目、减少不必要段距、调整图片环绕和页面级 override。达到质量硬下限后仍放不下，候选应阻断，而不是静默裁切。

## 视觉复核

渲染并检查全部页面。联系表用于发现密度和结构问题；首、中、末页、全部图表页、异常页和低字号风险页必须按原尺寸打开。缩略图不能证明细小文字可读。
