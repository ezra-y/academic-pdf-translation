# 设计依据

这份文件说明规则来自哪里，避免把默认选择写成普遍事实。

## 实测结论

- 通用自动路线适合规则正文，但不能稳定覆盖量表、固定表单、复杂表格和模型图。
- 双栏重排工具可能改善段落流，也可能产生小字号、图内漏译、异常字符或
  阅读顺序错误，因此不能直接成为交付标准。
- 历史译本可以帮助发现压行距、正文上挤和大面积空白，但不能作为排版金标准。

## 默认质量选择

以下是默认交付合同，不声称是所有出版社的通用规范：

- 简体中文正文不低于 8 pt；
- 行距目标 1.50–1.60，优先约 1.55；
- 1.45–1.49 仅作有记录的溢出例外；
- 可读性第一；
- 除白名单外全文本地化；
- 基础检查始终通过；用户选择审校模式时，再由独立检查者通过。

## 工程策略

以下属于为提高稳定性而采用的工程设计：

- 先画像再分流；
- 译文与排版代码解耦；
- 自动底稿加复杂页 override；
- JSON 作为稳定作业接口；
- 自动 QA 只给出阻断或进入人工审查；
- 多语言使用配置扩展，不复制流水线。

这些策略需要通过持续前向测试迭代，但不影响已经成立的质量合同。
