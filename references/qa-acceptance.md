# QA 与验收

## 自动硬门槛

- `body_regions`、`non_body_regions` 和页面 override 均可使用单页
  `page` 或批量 `pages` 选择器；两者的作用范围必须一致。
- 旋转 90/270 度的页面按 PDF 未旋转媒体框核对文本坐标，避免把合法
  横向内容误判为越界。
- 明确标记为结构化表格的页面不采用易受 PDF 文本分组影响的整块文本框
  相交结果作为硬失败；仍执行字符 span 重叠检查，并强制逐页原尺寸目视。
- 源位图被完整中文矢量重绘时，必须在页面 override 或图表清单中记录
  重建方式、页面和理由，才能解释图像对象数量减少。
- 页数一致；
- 逐页尺寸一致，除非任务明确批准新版式；
- 目标语言文本层非空、可复制、可检索；
- 字体可读取并可靠嵌入；
- 正文字号和行距达到作业冻结配置；
- 明确标记的结构化表格区域执行独立字号门禁；简体中文项目默认表内可读文字
  不得低于 7 pt，不能通过把表格标成非正文来绕过正文 8 pt 门槛；
- 无明显文本块重叠、越界、裁切、空白页、空字符、替换字符和占位符；
- 中文任务无兼容汉字；
- 不出现“正文压紧但同栏仍有大面积可用空白”；
- 底部可用空白达到约 25% 的页面必须进入稀疏页人工复核；若正文同时低于优选字号或优选行距，直接阻断；
- 同一页译文底部空白比原文多出 25 个百分点以上时，继续比较顶部与底部留白；
- 单栏页以跨页面中线的连续宽行识别，不得仅按文本行中心落在左半或右半而误拆成双栏；真实双栏仍按较短栏检查底部留白；
  只有底部比顶部再多出至少约 20 个百分点、形成明显“上挤下空”时才直接
  阻断。上下相对平衡、字号行距达标且横向版心正常的天然短页进入人工复核，
  不得通过机械下移整页、极端拉大段距或收窄栏宽来消除单一底部指标；
- 普通正文的中位行宽若低于原文的 72%，且横向页面占比同时缩小至少
  12 个百分点，判为 `BODY_WIDTH_COLLAPSE_VS_SOURCE` 并直接阻断；
  这项门槛防止通过收窄版心来减少底部留白。只有任务明确批准新版式并在
  页面 override 中记录理由时才能例外；
- 中文长标题或正文紧接着出现单个汉字续行时，判为
  `ORPHAN_SINGLE_HAN_LINE` 并直接阻断；具有明确层级和充分前后间距的
  单字章节编号不在此列；
- 普通正文页的正文中位字号相对全篇文档级字号偏差超过约 `0.35pt` 时，
  判为 `BODY_FONT_INCONSISTENT_ACROSS_DOCUMENT`；应以最密页试排结果
  冻结全篇字号，不得逐页缩放；
- 同页出现至少两处超过约 `4` 倍正文字号的段间空档，或单处超过约 `8`
  倍正文字号时，判为 `PARAGRAPH_GAP_INFLATION`；特殊表单或明确分区页
  只有在页面 override 中记录 `paragraph_gap_inflation_justified: true`
  和具体理由后才可进入人工复核；
- 若 `layout_overrides.json` 记录了完整的 `document_typography`：
  `selection_method: densest-page-fit`、全篇字号锁定、统一行距、自然段距和
  选择理由，则已通过其他门禁的剩余短页留白改列
  `NATURAL_SHORT_PAGE_AFTER_DOCUMENT_TYPOGRAPHY` 人工风险；这只取消
  自动硬失败，不构成 PASS，仍须逐页原尺寸复核。
- 图、表、附录和页面结构未明显缺失；图片被矢量重建时必须在页面 override 中说明；
- 无内部 ID、调试文本或模板标记。
- 候选来源记录绑定当前 `translation.json` 与 `layout_overrides.json` 哈希；
- 候选 PDF 中可定位到足够比例的实际译文，而不只是存在目标语言字符；
- 标题，以及标记为 `semantic-boundary`、`semantic-high-risk`、
  `statistics-or-sample` 或 `instrument-item-or-scoring` 的高风险单元，
  必须逐单元精确出现在候选文本层；任何以 `-item-or-scoring` 结尾的历史
  工具专属标记按同等规则处理。表格因文本抽取顺序不稳定，仍由数值与结构
  清单负责，审校模式再由独立检查确认。整篇覆盖率不能掩盖关键一句被静默改写；
- `audit_translation_completeness.py` 检出的严重正文压缩、统计锚点大量丢失，
  或复杂图表声明与候选实际结构不符，会在注册前生成返修任务并返回制作环节；

自动检测无法稳定证明所有重叠、裁切和图内文字状态，因此报告将可确定问题列为硬失败，把不确定项列为人工风险。

## 翻译完整性

- 不得存在白名单外的普通原文段落；
- 标题、表头、承担论文信息的图内标签与界面文字、脚注和声明不得漏译；
- 所有保留原文都在 `retained_source.json` 中；
- `figure_inventory.json` 中每项必须是 `translated` 或 `not-applicable`，不能有 `unresolved`。
- 相邻语义单元不得出现源文未对应的长后缀/前缀重复；跨栏、跨页续句只能在
  数据层拆分一次，不能靠生成器隐藏重复译文。

PDF 文本提取无法证明位图内部文字已经翻译。需要本地化的图内文字必须同时
依靠清单和视觉复核；照片、装饰图、正式标志和不依赖内部文字理解的图片按
清单理由保持原图或省略，不得机械覆盖译文。

原文结构提取也不能只依赖 `page.get_text("text")`。作业必须保留 PDF 原生对象
顺序和按坐标、栏位推断的顺序；二者明显冲突的页进入看图确认。规则双栏正文
可以继续使用可靠文字层，表格、模型图、扫描页和顺序冲突页才升级为视觉处理，
避免全篇逐页看图造成不必要的速度损失。

## 自动报告结论

- `NEEDS_REPAIR`：候选暂不注册，按返修任务集中修复并重新预检；
- `READY_FOR_HUMAN_REVIEW`：基础检查通过；是否继续独立检查由作业模式决定。

自动脚本不输出最终 PASS。

写出 PDF 前先使用 `pre_render_audit.py` 汇总检查译文、复杂页载荷、字体和
排版器试排合同。正式注册前再使用 `preflight_candidate.py` 在临时作业副本
运行同一套自动门槛，预检失败不得增加
`candidate_provenance.iteration`。统一生成器的同一代码构建只允许首检和
集中返修后复检；第二次仍失败时必须修复排版器并产生新的构建哈希。注册后使用
`review_risk_report.py` 汇总逐页疑似摘要化、正文翻译单元中的年份锚点、
URL/DOI 和检索字符风险；页眉、页脚和出版信息不参与年份检查。报告先列
高优先风险页，再列普通核对页，供独立复审安排顺序。

## 必须保留的证据

- `qa.json`；
- 原文和最终候选哈希。
- 若发生重译，上一轮完整证据归档和本轮修复原因。

平衡档和精细档额外保留：

- 按顺序覆盖全部页面的源译对照图包、索引及 manifest；
- 疑点页按需生成的高清源译对照图；
- 独立检查 JSON。

## 最终 PASS

快速档需要自动门槛、原文残留审计和图表清单通过。平衡档和精细档都只需要
一轮完整复审及必要时的一次集中返修；精细档只扩大返修后的局部确认范围，
任何单一指标不能替代对应档位的完整决定。

## 错误类别

- `TRANSLATION_INCOMPLETE`
- `SEMANTIC_FIDELITY_FAIL`
- `FONT_RENDER_FAIL`
- `READABILITY_FAIL`
- `LAYOUT_OVERLAP_FAIL`
- `IMAGE_TEXT_FAIL`
- `TABLE_STRUCTURE_FAIL`
- `REFERENCE_BOUNDARY_FAIL`
- `INTEGRATION_FAIL`
